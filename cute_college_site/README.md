# College Girl Survival Guide

A cute and supportive final project website designed for college girls. It includes sections on mental health, friendships, academics, budgeting, and safety.

## Built with
- HTML
- CSS
- Vanilla JavaScript
- Chart.js

## Features
- Random big sister quote button
- Stress level slider
- Friendship quiz
- Academic planner with local storage
- Budget calculator with chart
- Safety tip cards
- Reminder popup
- Heart trail effect

## Best viewed on
Desktop, but it also works on mobile.
